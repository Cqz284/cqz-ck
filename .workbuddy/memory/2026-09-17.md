## 新功能：记账页循环标签条（拖拽/弹性/居中选中/加号）

用户需求：标签一行横排、拖拽跟手且最右补到最左（循环）、落位后居中项自动选中、点选弹性居中、加号可新增标签。
用户确认的四个决策：拖拽跟手+松手落位 / 居中者自动选中 / 真实换位并记住顺序 / 弹窗输入+持久保存。

### 关键设计结论（复用价值高）
- **循环轮转不改变环序**：拖拽是循环移位，环上相邻关系不变。因此"记住顺序" = 持久化「标签列表 + 当前居中标签」两元组（`QuickTagsStore { tags, center }`，键 `ledger:quick-tags`），重进页面按原序渲染并把 center 摆到正中即可完整还原画面。**不要**把数组"旋转归一化"后存储——若环内还有"+"这类非标签项，归一化会让它的相对位置跳变。
- **三份拷贝 + 相位取模**：轨道 = 环 ×3，相位 p（轨道坐标系中对准容器中线的 x）用 `wrapPhase` 折回 [C/2, 3C/2)，可见窗口始终落在拷贝覆盖范围内，画面无缝；translateX = 容器半宽 - p。
- **手势分层**：touchmove 先做方向锁定（|dx|≥|dy| 才接管，纵向让给页面滚动）；tap 用 moved 标志抑制拖拽后的误触；松手按末速（最近 100ms 采样）× 140ms 外推，再 `nearestCenter` 吸附 + 弹性 transition（cubic-bezier(0.22,1.32,0.36,1)）。
- **变宽标签**：项宽不定（2 字 vs 20 字），用实测宽度前缀和 `buildLayout` 而非等宽槽位；新增/旋转后无需重测（旋转时 widths 同步旋转）。

## Bug 修复：快速滑动时的异常回弹

- **现象**：快速往右滑动标签条，甩出去后又猛地弹回
- **根因**：相位 `p` 只在安全区间 `[C/2, 3C/2)` 内取值，而惯性外推是**无界**的。当 `|v × 140ms|` 接近或超过半个环周长时（例：490px 外推 vs 490px 环周长），从外推点看"最近的项"在环上翻到了手指的反方向 → 单看数值只差 24px，方向却与滑动相反，于是被判成"该回到出发点附近"
- **修复（三处，都在 pages/ledger/edit/index.ts）**
  1. 惯性位移夹取：`flingShift()`（已提取到 utils/tag-strip.ts，纯函数+回归测试）——按"最多 3 项"与"最多 0.4 周长"双重夹取，保证落点必在滑动方向上
  2. `animateTo` 取**与当前相位最近的等价目标**：`to = target + round((from - target) / C) * C`。原实现直接 `wrapPhase(target)` 会把目标整体平移一个周长，导致"点旁边一格却绕了快一整圈"（同类取模 bug 的第二个表现）
  3. 动画结束后 `scheduleNormalize()` 静默折回安全区间（对环同余，画面不变），保持数值不发散
- **顺带优化**
  - 过渡时长随位移自适应（300ms + 0.35ms/px，夹在 [260, 620]）：长距离不再"又快又弹"
  - 两条缓动曲线：位移 >140px 用 `cubic-bezier(0.22,1.06,0.36,1)`（几乎不回弹），短距离保留 `1.32` 的回弹手感
  - 动画中途手指按下用 `currentPhase()`（easeOutCubic 插值）接管，消除"从逻辑终点起算"的跳变
  - `anim: boolean` 改为 `tween: string`（直接内联 transition 片段），支持动态时长/曲线
- **验证**：tsc clean；jest --ci **9 suites / 119 tests** 全通过（新增 4 个 flingShift 回归用例，含"位移 + 半个项距 < 半个环"的不变量断言）

## 标签删除 + 加号视觉优化 + 静态行降级

用户反馈：① 标签无法删除；② 加号随标签移动时不好看。用户确认的决策：长按进入管理态 / 不设删除下限（自适应兜底）/ 加号改实心圆形+居中放大+外侧淡出 / 删掉选中项时自动选中下一个。

### 关键设计结论
- **小环必然重影，这是拷贝数解决不了的**：环周长 C < 屏宽 cc 时，同屏必然看到重复标签。因此新增**模式降级**：`C > cc` 用循环轨道（3 份拷贝 + 相位），`C ≤ cc` 自动切「静态行」（居中平铺、点选即选中、加号钉行尾）。两个模式共用同一份 `stripItems` 数据，仅是否应用 transform 不同。
- **焦点与选中分离**：`focus` = 停在中线的环内下标（含加号），驱动放大强调；`on`（高亮）= `!plus && i === focus`；`sel` = 最近一次居中的标签，仅用于持久化与初始定位。加号居中时不改变已选标签。
- **长按必须抑制当次 tap**：长按 450ms 进入管理态后抬手，该标签仍会触发 tap → 会立刻被删掉。用已有的 `moved` 标志抑制（`enterManage` 里置 true）。
- **管理态下 touchstart 不能提前 return**：否则 `moved` 永远停在 true，点 × 反而删不掉。正确做法是管理态也走 touchstart/touchmove 的复位与方向锁定，只是不位移（`dragging = false`）。
- **`get()` 必须区分「未存储」与「存储为空」**：前者首次使用返回默认标签，后者是用户删光了，必须如实返回空数组，否则删掉的标签会"复活"。`resetDefaults()` 作为找回入口。

## 加号固定右端 + 小环重影修复

用户看到只剩 1 个标签时的截图：环内"餐饮、加号"交替重复铺满一行（正是预警过的小环重影），并提出加号改为钉在尾部不转动。

### 变更要点
- **加号移出循环环**：循环模式下加号是独立元素 `.tag-strip__add`，绝对定位钉在右端（top 50% 垂直居中），`box-shadow: 0 0 0 12rpx var(--bg-color)` 用背景色光晕做视觉切割，标签从它下方滑过被干净隔开；环内只剩真标签，3 份拷贝。静态行模式下加号仍是行尾内联（`strip-item--plus`）。

## 取消滑动自动选中 / 真正水平居中 / 修复相位越界空白

用户反馈三点：① 取消"滑动落位自动选中"；② 标签并非真正水平居中；③ 快速持续同向滑动时出现标签不显示。

### ① 取消滑动自动选中
- `animateTo(target, centerIdx, selectIdx?)` 增加第三个参数：只有显式传入才改变选中。拖拽落位只更新"中线标记"，不再改选中
- 语义拆分：`sel`（选中：高亮色 + 输入框 + 持久化）与 `center`（几何中线：缩放强调）彻底解耦
- 点选仍同时居中 + 选中；拖拽期间先清掉中线标记（`applyState(-1)`），落位后再标到新的中心项，避免放大的标签停在旧位置随手指漂移

### ② 真正水平居中
- 之前为给右端钉住的加号让位，中线被左移了半个加号区（`(cc - 50)/2`），视觉上确实偏左
- 改为 `cc / 2`：加号是覆盖层，靠 64rpx 渐隐遮罩 + 12rpx 背景色光圈切割，不参与占位
- 静态行判据同步简化为 `C <= cc`

### ③ 相位越界导致空白（真 bug）
- **根因**：相位 p 必须留在 3 份拷贝的渲染范围内，否则可见窗口滑出覆盖范围 → 空白。旧实现只在动画结束后 40ms 用 `scheduleNormalize` 折回；连续快速滑动时下一次 touchstart 会清掉该定时器，p 一直停在越界位置
- **修复**：新增纯函数 `planTween(current, target, C)`（utils/tag-strip.ts），一步同时完成两件事：
  1. 取"离当前最近的等价目标"，位移最短（避免绕整圈）

- **为什么不能只收终点**：起点也会被平移出安全区（相位贴近边界时反向操作必现）。必须整体平移、保持位移不变

## 修复：滑动时"异常滚回"（上一条修复引入的回归）

- **现象**：滑动时标签条莫名倒卷/滚回
- **根因**：上面 ③ 的"把 from/to 整体平移 k 个环周长"虽然对环同余、终点画面正确，但
  **CSS transition 是在位移数值空间线性插值的**：元素当前实际位移与新位移相差 `k*C`，
  浏览器会老老实实把这一个环周长扫过去。图案周期性强，终点看不出错，路径上却白扫一整圈
  → 观感就是"异常滚回"。**"对环同余"只保证端点等价，不保证路径等价。**
- **修复**（`planTween` 增加 `safeMin` 参数 + 返回 `shift` 标记）
  1. **能不平移就不平移**：起止点都落在渲染安全区 `[cc/2, 3C - cc/2]` 时直接返回 `shift:false`，
     此时过渡扫过的距离就是真实位移（绝大多数情况走这条路径）
  2. **必须平移时**（相位贴近安全区边界）：先做一次**无过渡的静默落位**跳到平移后的等价位置
     （对环同余、画面完全一致、看不见），再在 `wx.nextTick` 里启动真正的过渡，
     此时扫描距离等于真实位移
  3. 新增 `tweenToken` 动画令牌：`wx.nextTick` 回调与 touchstart/measure 比对令牌，
     作废过期的延迟启动，避免与新手势打架
- **通用教训**：涉及"周期图案 + CSS 过渡"时，凡是改变位移基准的操作都必须与过渡分离
  （先静默重绘、下一帧再动画），否则插值会沿数值空间走而不是沿视觉等价路径走
